This repository contains my **personal website**.

### ⚙️ Tech Stack
- 🧱 Static Site Generator: **Hugo**
- 🎨 Theme: **Blowfish** (Git Submodule)
- ⚡ CI/CD: **GitHub Actions**
- 📦 Config: Blowfish default configuration ([`config/_default`](config/_default))

### 📁 Project Structure
```
.
├── config/_default/     # Hugo & Blowfish configuration
├── content/             # Website content (posts/pages)
├── themes/
│   └── blowfish/        # Git submodule
├── static/              # Static assets (images, files)
├── layouts/             # Custom layouts (optional)
├── readme.md            # Repository information
```
